<b>ABOUT</b>

SINIWEBS is an independent digital studio focused on building premium websites, AI-powered systems and distinctive digital experiences.

This repository contains the source code for the SINIWEBS studio website.

The website was designed as an experience first — combining editorial typography, cinematic visuals, interactive motion and WebGL-based elements instead of following a conventional agency or SaaS template.

<i>Build something that feels like a digital experience, not just another website.</i>

<b>CREATIVE DIRECTION</b>

The visual direction of SINIWEBS is built around a restrained, cinematic design language.

• Minimal and editorial
• Dark, atmospheric foundation
• Warm, high-contrast typography
• Subtle motion instead of excessive animation
• Interactive elements with purpose
• Selective use of 3D and WebGL
• Strong visual hierarchy
• Clear paths from exploration to conversion

The goal was to create a website that feels premium without relying on generic gradients, template layouts, unnecessary cards or decorative effects.

The overall experience follows:

<b>Discover → Explore → Understand → Trust → Start a Project</b>

<b>THE EXPERIENCE</b>

The website includes:

• Cinematic hero experience

<b>WHY THESE TECHNOLOGIES</b>

<b>Next.js</b>

Used as the foundation of the application for its React architecture, routing, performance and production-ready development environment.

<b>React</b>

Used to build the interface as reusable interactive components rather than a single static page.

<b>TypeScript</b>

Used throughout the project to improve type safety, maintainability and development reliability.

<b>Three.js + React Three Fiber</b>

Used to create the WebGL and 3D layer of the experience.

3D was introduced selectively where depth, movement and spatial interaction could improve the experience rather than being used purely as decoration.

<b>React Three Fiber + Drei</b>

Used to integrate Three.js into the React component architecture and simplify the development of interactive 3D elements.

<b>GSAP</b>

Used for controlled animations, transitions, reveals and motion choreography across the interface.

<b>Lenis</b>

Used to create smooth scrolling and improve the relationship between scrolling, motion and page transitions.

<b>Tailwind CSS</b>

Used alongside custom CSS to build and manage responsive interface styling.

<b>DESIGN PHILOSOPHY</b>

SINIWEBS was not built around the idea of adding as many effects as possible.

It was built around a simpler principle:

<i>Every interaction should earn its place.</i>

Motion should guide attention.

3D should create depth.

Typography should establish identity.

Space should create focus.

And the interface should ultimately make people want to explore.

<b>RUN LOCALLY</b>

You will need:

• Node.js
• npm
• Git

Clone the repository:

git clone https://github.com/Nitinjaiiin/SINIWEBS.git

Move into the project directory:

cd SINIWEBS

Install the project dependencies:

npm install

Start the development server:

npm run dev

Open the local development environment:

http://localhost:3000

The development server will automatically update as you modify the source code.

<b>AVAILABLE SCRIPTS</b>

Start the development server:

npm run dev

Create a production build:

npm run build

Start the production server:

npm start

Run ESLint:

npm run lint

<b>PRODUCTION BUILD</b>

To test the production version locally:

npm run build

After the build completes:

npm start

The production application will then be available through the local Next.js server.
